## How to add a logo

1. Save SVG (preferred) or PNG as:
   `beefoo-front/public/logos/{slug}.svg`
   Example: `public/logos/pepsi.svg`
2. Re-export catalog:
   ```bash
   cd beefoo-back
   .venv/bin/python -m scripts.export_catalog
   ```
3. Refresh the site.

Already working local logos: `chanel.svg`, `disney.svg`, `gucci.svg`
